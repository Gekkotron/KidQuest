# KidQuest v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a standalone Kotlin Multiplatform (Android + iOS) chore-points app: children, one-tap point awards/penalties with undo, configurable actions and quick buttons, solo/shared goals with celebration and split redemption, levels and streaks.

**Architecture:** Gradle modules `shared` (pure domain calculators + Room KMP data layer, also targets JVM so all logic tests run on the JVM), `composeApp` (Compose Multiplatform UI, ViewModels, Koin DI, compiled as a KMP library for Android/iOS/JVM), `androidApp` (thin Android application), `iosApp` (thin SwiftUI host generated with XcodeGen). `PointEvent` rows are the single source of truth; balances, levels, streaks and goal progress are derived.

**Tech Stack:** Kotlin 2.3.21, Compose Multiplatform 1.11.1, AGP 9.4.1, Gradle 9.7.1, KSP 2.3.12, Room 2.8.5 + `sqlite-bundled`, Koin 4.1.1, kotlinx-datetime 0.7.1, kotlinx-coroutines 1.11.0, JetBrains navigation-compose (type-safe routes), kotlin.test, Turbine, Compose UI test (JVM).

**Spec:** `docs/superpowers/specs/2026-10-11-kidquest-design.md`

## Review Focus

1. **Undo after the snackbar is gone** (app restarted, minutes later): undo from Child detail history must restore the balance and re-evaluate goals — pinned in Task 6 (`undoLongAfterAward_restoresBalanceAndGoalStatus`).
2. **Redeeming a shared goal when one child's balance is below their share or negative**: allowed, balance goes (more) negative, and that child's *other* achieved goals drop back to ACTIVE — pinned in Task 7 (`redeemDropsOtherGoalsOfMembersBackToActive`).
3. **Editing an ACHIEVED goal's cost upward or removing a member** must flip it back to ACTIVE silently (no celebration) — pinned in Task 7 (`editingAchievedGoalAboveProgress_revertsToActiveWithoutEvent`).
4. **Deleting a PointAction that past events reference**: history must still show the event label — pinned in Task 7 (`deletingActionKeepsHistoryLabel`).
5. **Day boundary and DST**: awards at 23:59 and 00:01 local are two days; the Europe/Paris DST change does not merge/split days — pinned in Task 3 (`DayMapperTest`).

```kotlin
package com.gekkotron.kidquest.domain

import kotlin.math.floor
import kotlin.math.sqrt

/** Levels are driven by lifetime AWARD points. Level 1 starts at 0. */
object LevelCalculator {

    /** Points needed to reach [level]: floor(100 · (level−1)^1.5). Computed as 100·k·√k to stay exact on perfect squares. */
    fun threshold(level: Int): Int {
        require(level >= 1) { "level must be >= 1" }
        val k = (level - 1).toDouble()
        return floor(100.0 * k * sqrt(k)).toInt()
    }

    fun levelFor(lifetime: Int): Int {
        var level = 1
        while (threshold(level + 1) <= lifetime) level++
        return level
    }

    /** Fraction [0, 1) of the way from the current level to the next. */
    fun progress(lifetime: Int): Float {
        if (lifetime <= 0) return 0f
        val level = levelFor(lifetime)
        val start = threshold(level)
        val end = threshold(level + 1)
        return (lifetime - start).toFloat() / (end - start).toFloat()
    }
}
```

```kotlin
import kotlinx.datetime.DateTimeUnit
import kotlinx.datetime.LocalDate
import kotlinx.datetime.minus

object StreakCalculator {
    /** Consecutive days with an award, ending today or (if today has none yet) yesterday. */
    fun streak(awardDays: Set<LocalDate>, today: LocalDate): Int {
        val yesterday = today.minus(1, DateTimeUnit.DAY)
        var day = when {
            today in awardDays -> today
            yesterday in awardDays -> yesterday
            else -> return 0
        }
        var count = 0
        while (day in awardDays) {
            count++
            day = day.minus(1, DateTimeUnit.DAY)
        }
        return count
    }
}
```

```kotlin
package com.gekkotron.kidquest.domain

object GoalProgressCalculator {
    /** Sum of member balances, each clamped at 0 so a negative balance never drags a shared goal down. */
    fun contributed(memberBalances: Collection<Int>): Int = memberBalances.sumOf { maxOf(0, it) }

    fun progress(memberBalances: Collection<Int>, cost: Int): Float {
        require(cost > 0) { "cost must be > 0" }
        return (contributed(memberBalances).toFloat() / cost).coerceIn(0f, 1f)
    }

    fun isReached(memberBalances: Collection<Int>, cost: Int): Boolean =
        contributed(memberBalances) >= cost
}
```

```kotlin
package com.gekkotron.kidquest.domain

object RedeemSplitter {
    /** Equal shares; the remainder goes one point at a time to members in the given order (oldest child first). */
    fun equal(cost: Int, orderedMemberIds: List<Long>): Map<Long, Int> {
        require(orderedMemberIds.isNotEmpty()) { "goal has no members" }
        val base = cost / orderedMemberIds.size
        val remainder = cost % orderedMemberIds.size
        return orderedMemberIds.mapIndexed { i, id -> id to base + if (i < remainder) 1 else 0 }.toMap()
    }

    fun isValid(cost: Int, memberIds: Set<Long>, split: Map<Long, Int>): Boolean =
        split.keys == memberIds && split.values.all { it >= 0 } && split.values.sum() == cost
}
```

```kotlin
package com.gekkotron.kidquest.data

import com.gekkotron.kidquest.domain.GoalProgressCalculator
import kotlin.time.Clock

/** Keeps goal status in sync with balances. Call inside a transaction; emit the returned events after commit. */
class GoalStatusUpdater(
    private val goalDao: GoalDao,
    private val pointDao: PointEventDao,
    private val clock: Clock,
) {
    suspend fun refreshForChildren(childIds: Collection<Long>): List<AppEvent> {
        if (childIds.isEmpty()) return emptyList()
        return goalDao.openGoalsForChildren(childIds.distinct()).mapNotNull { refresh(it) }
    }

    suspend fun refreshGoal(goalId: Long): AppEvent? = goalDao.get(goalId)?.let { refresh(it) }

    private suspend fun refresh(goal: Goal): AppEvent? {
        if (goal.status == GoalStatus.REDEEMED) return null
        val balances = goalDao.memberIds(goal.id).map { pointDao.balance(it) }
        val reached = balances.isNotEmpty() && GoalProgressCalculator.isReached(balances, goal.cost)
        return when {
            goal.status == GoalStatus.ACTIVE && reached -> {
                goalDao.update(goal.copy(status = GoalStatus.ACHIEVED, achievedAt = clock.now().toEpochMilliseconds()))
                AppEvent.GoalAchieved(goal.id, goal.title, goal.icon)
            }
            goal.status == GoalStatus.ACHIEVED && !reached -> {
                goalDao.update(goal.copy(status = GoalStatus.ACTIVE, achievedAt = null))
                null
            }
            else -> null
        }
    }
}
```

```kotlin
package com.gekkotron.kidquest.data

import com.gekkotron.kidquest.domain.LevelCalculator
import kotlinx.coroutines.flow.Flow
import kotlin.time.Clock

class PointRepository(
    private val db: KidQuestDatabase,
    private val updater: GoalStatusUpdater,
    private val bus: AppEventBus,
    private val clock: Clock,
) {
    private val points = db.pointEventDao()
    private val goals = db.goalDao()
    private val children = db.childDao()

    /** Awards (delta > 0) or penalises (delta < 0) a child. Returns the new event id. */
    suspend fun apply(childId: Long, delta: Int, label: String, actionId: Long? = null): Long {
        require(delta != 0) { "delta must not be 0" }
        val type = if (delta > 0) PointEventType.AWARD else PointEventType.PENALTY
        val (id, events) = db.tx {
            val lifetimeBefore = points.lifetime(childId)
            val id = points.insert(
                PointEvent(
                    childId = childId, delta = delta, type = type, actionId = actionId,
                    label = label, timestamp = clock.now().toEpochMilliseconds(),
                )
            )
            val events = updater.refreshForChildren(listOf(childId)).toMutableList()
            if (type == PointEventType.AWARD) {
                val newLevel = LevelCalculator.levelFor(lifetimeBefore + delta)
                if (newLevel > LevelCalculator.levelFor(lifetimeBefore)) {
                    events += AppEvent.LevelUp(childId, children.get(childId)?.name.orEmpty(), newLevel)
                }
            }
            id to events
        }
        events.forEach(bus::emit)
        return id
    }

    /** Undoes one event. Undoing any REDEEM event undoes the whole redemption and puts the goal back to ACHIEVED. */
    suspend fun undo(eventId: Long) {
        val events = db.tx {
            val event = points.get(eventId) ?: return@tx emptyList()
            if (event.undone) return@tx emptyList()
            val goalId = event.goalId
            if (event.type == PointEventType.REDEEM && goalId != null) {
                points.setRedeemUndone(goalId, true)
                goals.get(goalId)?.let { goals.update(it.copy(status = GoalStatus.ACHIEVED, redeemedAt = null)) }
                updater.refreshForChildren(goals.memberIds(goalId))
            } else {
                points.setUndone(eventId, true)
                updater.refreshForChildren(listOf(event.childId))
            }
        }
        events.forEach(bus::emit)
    }

    /** Re-applies an undone AWARD/PENALTY. Returns false for REDEEM events or unknown ids. */
    suspend fun restore(eventId: Long): Boolean {
        var restored = false
        val events = db.tx {
            val event = points.get(eventId) ?: return@tx emptyList()
            if (event.type == PointEventType.REDEEM || !event.undone) return@tx emptyList()
            points.setUndone(eventId, false)
            restored = true
            updater.refreshForChildren(listOf(event.childId))
        }
        events.forEach(bus::emit)
        return restored
    }

    fun history(childId: Long): Flow<List<PointEvent>> = points.observeHistory(childId)
}
```

```kotlin
package com.gekkotron.kidquest.data

import com.gekkotron.kidquest.domain.GoalProgressCalculator
import com.gekkotron.kidquest.domain.RedeemSplitter
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.combine
import kotlin.time.Clock

class GoalRepository(
    private val db: KidQuestDatabase,
    private val updater: GoalStatusUpdater,
    private val bus: AppEventBus,
    private val clock: Clock,
) {
    private val goals = db.goalDao()
    private val children = db.childDao()
    private val points = db.pointEventDao()

    fun observeGoals(): Flow<List<GoalSummary>> =
        combine(goals.observeAll(), children.observeAll(), points.observeTotals()) { all, kids, totals ->
            val kidsById = kids.associateBy { it.id }
            val balances = totals.associate { it.childId to it.balance }
            all.map { gwm ->
                val members = gwm.members.mapNotNull { kidsById[it.childId] }.sortedWith(compareBy({ it.createdAt }, { it.id }))
                val memberBalances = members.map { balances[it.id] ?: 0 }
                GoalSummary(
                    goal = gwm.goal,
                    members = members,
                    contributed = GoalProgressCalculator.contributed(memberBalances),
                    progress = GoalProgressCalculator.progress(memberBalances, gwm.goal.cost),
                )
            }
        }

    suspend fun get(goalId: Long): Goal? = goals.get(goalId)

    suspend fun memberIds(goalId: Long): List<Long> = goals.memberIds(goalId)

    suspend fun create(title: String, icon: String, cost: Int, memberIds: Set<Long>): Long {
        validate(title, cost, memberIds)
        val (id, event) = db.tx {
            val id = goals.insert(Goal(title = title.trim(), icon = icon, cost = cost, createdAt = clock.now().toEpochMilliseconds()))
            goals.insertMembers(memberIds.map { GoalMember(id, it) })
            id to updater.refreshGoal(id)
        }
        event?.let(bus::emit)
        return id
    }

    suspend fun update(goalId: Long, title: String, icon: String, cost: Int, memberIds: Set<Long>) {
        validate(title, cost, memberIds)
        val event = db.tx {
            val goal = checkNotNull(goals.get(goalId)) { "goal $goalId not found" }
            check(goal.status != GoalStatus.REDEEMED) { "redeemed goals cannot be edited" }
            goals.update(goal.copy(title = title.trim(), icon = icon, cost = cost))
            goals.deleteMembers(goalId)
            goals.insertMembers(memberIds.map { GoalMember(goalId, it) })
            updater.refreshGoal(goalId)
        }
        event?.let(bus::emit)
    }

    suspend fun delete(goalId: Long) {
        db.tx {
            val goal = goals.get(goalId) ?: return@tx
            check(goal.status != GoalStatus.REDEEMED) { "redeemed goals are kept for history" }
            goals.delete(goalId) // goal_member rows cascade
        }
    }

    /** Equal split, remainder to the oldest children first. */
    suspend fun defaultSplit(goalId: Long): Map<Long, Int> {
        val goal = checkNotNull(goals.get(goalId)) { "goal $goalId not found" }
        val ordered = children.getByIds(goals.memberIds(goalId)).map { it.id }
        return RedeemSplitter.equal(goal.cost, ordered)
    }

    suspend fun redeem(goalId: Long, split: Map<Long, Int>) {
        val events = db.tx {
            val goal = checkNotNull(goals.get(goalId)) { "goal $goalId not found" }
            check(goal.status == GoalStatus.ACHIEVED) { "only achieved goals can be redeemed" }
            val members = goals.memberIds(goalId)
            require(RedeemSplitter.isValid(goal.cost, members.toSet(), split)) { "invalid split $split for cost ${goal.cost}" }
            val now = clock.now().toEpochMilliseconds()
            split.filterValues { it > 0 }.forEach { (childId, amount) ->
                points.insert(
                    PointEvent(childId = childId, delta = -amount, type = PointEventType.REDEEM, goalId = goalId, label = goal.title, timestamp = now)
                )
            }
            goals.update(goal.copy(status = GoalStatus.REDEEMED, redeemedAt = now))
            updater.refreshForChildren(members)
        }
        events.forEach(bus::emit)
    }

    suspend fun restart(goalId: Long): Long {
        val goal = checkNotNull(goals.get(goalId)) { "goal $goalId not found" }
        return create(goal.title, goal.icon, goal.cost, goals.memberIds(goalId).toSet())
    }

    private fun validate(title: String, cost: Int, memberIds: Set<Long>) {
        require(title.isNotBlank()) { "title must not be blank" }
        require(cost > 0) { "cost must be > 0" }
        require(memberIds.isNotEmpty()) { "a goal needs at least one child" }
    }
}
```

```kotlin
    private val db: KidQuestDatabase,
    private val clock: Clock,
    private val timeZone: () -> TimeZone,

    private val children = db.childDao()
    private val points = db.pointEventDao()

    suspend fun add(name: String, avatar: String, color: Long): Long {
        require(name.isNotBlank()) { "name must not be blank" }
        return children.insert(Child(name = name.trim(), avatar = avatar, color = color, createdAt = clock.now().toEpochMilliseconds()))
    }

    suspend fun update(child: Child) {
        require(child.name.isNotBlank()) { "name must not be blank" }
        children.update(child.copy(name = child.name.trim()))
    }

    suspend fun setArchived(childId: Long, archived: Boolean) {
        val child = children.get(childId) ?: return
        children.update(child.copy(archived = archived))
    }

    fun observeAll(): Flow<List<Child>> = children.observeAll()

    /** "Today" is evaluated on each emission, so streaks refresh whenever data changes. */
    fun observeSummaries(includeArchived: Boolean = false): Flow<List<ChildSummary>> {
        val source = if (includeArchived) children.observeAll() else children.observeActive()
        return combine(source, points.observeTotals(), points.observeAwardTimestamps()) { kids, totals, awards ->
            val tz = timeZone()
            val today = DayMapper.toLocalDate(clock.now().toEpochMilliseconds(), tz)
            val totalsById = totals.associateBy { it.childId }
            val daysById = awards.groupBy({ it.childId }, { DayMapper.toLocalDate(it.timestamp, tz) }).mapValues { it.value.toSet() }
            kids.map { child ->
                val t = totalsById[child.id]
                val lifetime = t?.lifetime ?: 0
                ChildSummary(
                    child = child,
                    balance = t?.balance ?: 0,
                    lifetime = lifetime,
                    level = LevelCalculator.levelFor(lifetime),
                    levelProgress = LevelCalculator.progress(lifetime),
                    streak = StreakCalculator.streak(daysById[child.id].orEmpty(), today),
                )
            }
        }
    }
}
```

```kotlin
package com.gekkotron.kidquest.data

import kotlinx.coroutines.flow.Flow

class SettingsRepository(private val db: KidQuestDatabase) {
    private val dao = db.settingsDao()

    fun observeActions(): Flow<List<PointAction>> = dao.observeActions()

    suspend fun addAction(label: String, points: Int, icon: String) {
        require(label.isNotBlank()) { "label must not be blank" }
        require(points != 0) { "points must not be 0" }
        val next = (dao.actions().maxOfOrNull { it.sortOrder } ?: -1) + 1
        dao.insertAction(PointAction(label = label.trim(), points = points, icon = icon, sortOrder = next))
    }

    suspend fun updateAction(action: PointAction) {
        require(action.label.isNotBlank()) { "label must not be blank" }
        require(action.points != 0) { "points must not be 0" }
        dao.updateActions(action.copy(label = action.label.trim()))
    }

    suspend fun deleteAction(action: PointAction) = dao.deleteAction(action)

    suspend fun moveAction(actionId: Long, up: Boolean) = db.tx {
        val reordered = swapped(dao.actions(), actionId, up, { it.id }) ?: return@tx
        dao.updateActions(*reordered.mapIndexed { i, a -> a.copy(sortOrder = i) }.toTypedArray())
    }

    fun observeQuickAmounts(): Flow<List<QuickAmount>> = dao.observeQuickAmounts()

    suspend fun addQuickAmount(points: Int) {
        require(points != 0) { "points must not be 0" }
        val next = (dao.quickAmounts().maxOfOrNull { it.sortOrder } ?: -1) + 1
        dao.insertQuickAmount(QuickAmount(points = points, sortOrder = next))
    }

    suspend fun updateQuickAmount(amount: QuickAmount) {
        require(amount.points != 0) { "points must not be 0" }
        dao.updateQuickAmounts(amount)
    }

    suspend fun deleteQuickAmount(amount: QuickAmount) = dao.deleteQuickAmount(amount)

    suspend fun moveQuickAmount(amountId: Long, up: Boolean) = db.tx {
        val reordered = swapped(dao.quickAmounts(), amountId, up, { it.id }) ?: return@tx
        dao.updateQuickAmounts(*reordered.mapIndexed { i, q -> q.copy(sortOrder = i) }.toTypedArray())
    }

    /** null = follow the system language. */
    fun observeLanguage(): Flow<String?> = dao.observeSetting(KEY_LANGUAGE)

    suspend fun setLanguage(tag: String?) {
        if (tag == null) dao.removeSetting(KEY_LANGUAGE) else dao.putSetting(AppSetting(KEY_LANGUAGE, tag))
    }

    private fun <T> swapped(items: List<T>, id: Long, up: Boolean, idOf: (T) -> Long): List<T>? {
        val index = items.indexOfFirst { idOf(it) == id }
        val target = if (up) index - 1 else index + 1
        if (index < 0 || target !in items.indices) return null
        return items.toMutableList().apply { add(target, removeAt(index)) }
    }

    private companion object {
        const val KEY_LANGUAGE = "language"
    }
}
```

```kotlin
import androidx.compose.runtime.ProvidedValue
```

```kotlin
import androidx.compose.ui.platform.LocalContext
import java.util.Locale

actual object LocalAppLocale {
    private var default: Locale? = null

    actual val current: String
        @Composable get() = Locale.getDefault().toString()

    @Composable
    actual infix fun provides(value: String?): ProvidedValue<*> {
        val configuration = LocalConfiguration.current
        if (default == null) default = Locale.getDefault()
        val new = if (value == null) default!! else Locale.forLanguageTag(value)
        Locale.setDefault(new)
        val updated = Configuration(configuration).apply { setLocale(new) }
        val resources = LocalContext.current.resources
        @Suppress("DEPRECATION")
        resources.updateConfiguration(updated, resources.displayMetrics)
        return LocalConfiguration.provides(updated)
    }
```

```kotlin
    private val default = NSLocale.preferredLanguages.first() as String
    private val local = staticCompositionLocalOf { default }

    actual val current: String
        @Composable get() = local.current

    @Composable
    actual infix fun provides(value: String?): ProvidedValue<*> {
        val new = value ?: default
        if (value == null) {
            NSUserDefaults.standardUserDefaults.removeObjectForKey(LANG_KEY)
        } else {
            NSUserDefaults.standardUserDefaults.setObject(arrayListOf(new), LANG_KEY)
        }
        return local.provides(new)
    }
```

```kotlin
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope

import com.gekkotron.kidquest.data.PointRepository
import com.gekkotron.kidquest.data.QuickAmount
import com.gekkotron.kidquest.data.SettingsRepository
import com.gekkotron.kidquest.ui.components.formatSigned
import kotlinx.coroutines.channels.Channel
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.receiveAsFlow
import kotlinx.coroutines.flow.stateIn
import kotlinx.coroutines.launch

data class ChildCard(val summary: ChildSummary, val closestGoal: GoalSummary?)

data class HomeUiState(
    val loading: Boolean = true,
    val children: List<ChildCard> = emptyList(),
    val goals: List<GoalSummary> = emptyList(),
    val quickAmounts: List<QuickAmount> = emptyList(),
    val actions: List<PointAction> = emptyList(),
)

sealed interface HomeEffect {
    data class Applied(val eventId: Long, val childName: String, val delta: Int) : HomeEffect
}

/** Highest-progress unfinished goal of the child, else an achieved one, else null. Redeemed goals are ignored. */
fun closestGoal(childId: Long, goals: List<GoalSummary>): GoalSummary? {
    val mine = goals.filter { g -> g.goal.status != GoalStatus.REDEEMED && g.members.any { it.id == childId } }
    return mine.filter { it.goal.status == GoalStatus.ACTIVE }.maxByOrNull { it.progress }
        ?: mine.firstOrNull { it.goal.status == GoalStatus.ACHIEVED }
}

class HomeViewModel(
    private val children: ChildRepository,
    goals: GoalRepository,
    private val points: PointRepository,
    settings: SettingsRepository,
) : ViewModel() {

    private val _effects = Channel<HomeEffect>(Channel.BUFFERED)
    val effects: Flow<HomeEffect> = _effects.receiveAsFlow()

    val state: StateFlow<HomeUiState> = combine(
        children.observeSummaries(),
        goals.observeGoals(),
        settings.observeQuickAmounts(),
        settings.observeActions(),
    ) { kids, allGoals, quick, actions ->
        val open = allGoals.filter { it.goal.status != GoalStatus.REDEEMED }
        HomeUiState(
            loading = false,
            children = kids.map { ChildCard(it, closestGoal(it.child.id, open)) },
            goals = open,
            quickAmounts = quick,
            actions = actions,
        )
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), HomeUiState())

    fun applyQuick(childId: Long, points: Int) = award(childId, points, formatSigned(points), null)

    fun applyAction(childId: Long, action: PointAction) = award(childId, action.points, action.label, action.id)

    fun undo(eventId: Long) {
        viewModelScope.launch { points.undo(eventId) }
    }

    fun addChild(name: String, avatar: String, color: Long): Boolean {
        if (name.isBlank()) return false
        viewModelScope.launch { children.add(name, avatar, color) }
        return true
    }

    private fun award(childId: Long, delta: Int, label: String, actionId: Long?) {
        viewModelScope.launch {
            val id = points.apply(childId, delta, label, actionId)
            val name = state.value.children.firstOrNull { it.summary.child.id == childId }?.summary?.child?.name.orEmpty()
            _effects.send(HomeEffect.Applied(id, name, delta))
        }
    }
}
```

```kotlin
package com.gekkotron.kidquest.ui.goals

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope

import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.SharingStarted
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.combine
import kotlinx.coroutines.flow.stateIn
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch

data class RedeemState(
    val goalId: Long,
    val title: String,
    val cost: Int,
    val members: List<Child>,
    /** Raw text per child, as typed in the dialog. */
    val shares: Map<Long, String>,
) {
    /** null when any share is not a non-negative integer. */
    val parsed: Map<Long, Int>? = shares.mapValues { it.value.trim().toIntOrNull() }
        .takeIf { m -> m.values.all { it != null && it >= 0 } }
        ?.mapValues { it.value!! }
    val total: Int = shares.values.sumOf { it.trim().toIntOrNull() ?: 0 }
    val isValid: Boolean = parsed?.let { RedeemSplitter.isValid(cost, members.map { m -> m.id }.toSet(), it) } ?: false
}

data class GoalsUiState(
    val loading: Boolean = true,
    val active: List<GoalSummary> = emptyList(),
    val achieved: List<GoalSummary> = emptyList(),
    val redeemed: List<GoalSummary> = emptyList(),
    val redeem: RedeemState? = null,
    val restartGoalId: Long? = null,
)

class GoalsViewModel(private val goals: GoalRepository) : ViewModel() {

    private data class Dialogs(val redeem: RedeemState? = null, val restartGoalId: Long? = null)
    private val dialogs = MutableStateFlow(Dialogs())

    val state: StateFlow<GoalsUiState> = combine(goals.observeGoals(), dialogs) { all, d ->
        GoalsUiState(
            loading = false,
            active = all.filter { it.goal.status == GoalStatus.ACTIVE },
            achieved = all.filter { it.goal.status == GoalStatus.ACHIEVED },
            redeemed = all.filter { it.goal.status == GoalStatus.REDEEMED },
            redeem = d.redeem,
            restartGoalId = d.restartGoalId,
        )
    }.stateIn(viewModelScope, SharingStarted.Eagerly, GoalsUiState())

    /** The Redeem button is only shown for loaded achieved goals, so the summary is always in state. */
    fun startRedeem(goalId: Long) {
        viewModelScope.launch {
            val summary = state.value.achieved.firstOrNull { it.goal.id == goalId } ?: return@launch
            val split = goals.defaultSplit(goalId)
            dialogs.update {
                it.copy(redeem = RedeemState(goalId, summary.goal.title, summary.goal.cost, summary.members, split.mapValues { e -> e.value.toString() }))
            }
        }
    }

    fun updateShare(childId: Long, text: String) {
        dialogs.update { d -> d.copy(redeem = d.redeem?.let { r -> r.copy(shares = r.shares + (childId to text)) }) }
    }

    fun cancelRedeem() = dialogs.update { it.copy(redeem = null) }

    fun confirmRedeem() {
        val r = dialogs.value.redeem ?: return
        val split = r.parsed?.takeIf { r.isValid } ?: return
        viewModelScope.launch {
            goals.redeem(r.goalId, split)
            dialogs.update { Dialogs(redeem = null, restartGoalId = r.goalId) }
        }
    }

    fun restart() {
        val id = dialogs.value.restartGoalId ?: return
        viewModelScope.launch {
            goals.restart(id)
            dialogs.update { it.copy(restartGoalId = null) }
        }
    }

    fun dismissRestart() = dialogs.update { it.copy(restartGoalId = null) }
}
```

```kotlin
import kotlinx.coroutines.flow.update

data class GoalEditUiState(
    val isNew: Boolean = true,
    val title: String = "",
    val icon: String = Palette.goalIcons.first(),
    val costText: String = "",
    val memberIds: Set<Long> = emptySet(),
    val children: List<Child> = emptyList(),
    val canDelete: Boolean = false,
    val done: Boolean = false,
) {
    val canSave: Boolean get() = title.isNotBlank() && (costText.toIntOrNull() ?: 0) > 0 && memberIds.isNotEmpty()
}

class GoalEditViewModel(
    private val goalId: Long,
    private val goals: GoalRepository,
    children: ChildRepository,
) : ViewModel() {

    private val _state = MutableStateFlow(GoalEditUiState(isNew = goalId == 0L))
    val state: StateFlow<GoalEditUiState> = _state.asStateFlow()

    init {
        viewModelScope.launch {
            if (goalId != 0L) {
                val goal = goals.get(goalId)
                if (goal != null) {
                    _state.update {
                        it.copy(
                            isNew = false, title = goal.title, icon = goal.icon, costText = goal.cost.toString(),
                            memberIds = goals.memberIds(goalId).toSet(), canDelete = goal.status != GoalStatus.REDEEMED,
                        )
                    }
                }
            }
        }
        viewModelScope.launch {
            children.observeAll().collect { all ->
                // Archived children stay visible only if already members.
                _state.update { s -> s.copy(children = all.filter { !it.archived || it.id in s.memberIds }) }
            }
        }
    }

    fun setTitle(value: String) = _state.update { it.copy(title = value) }
    fun setIcon(value: String) = _state.update { it.copy(icon = value) }
    fun setCost(value: String) = _state.update { it.copy(costText = value.filter(Char::isDigit).take(7)) }
    fun toggleMember(childId: Long) = _state.update {
        it.copy(memberIds = if (childId in it.memberIds) it.memberIds - childId else it.memberIds + childId)
    }

    fun save() {
        val s = _state.value
        if (!s.canSave) return
        viewModelScope.launch {
            val cost = s.costText.toInt()
            if (s.isNew) goals.create(s.title, s.icon, cost, s.memberIds) else goals.update(goalId, s.title, s.icon, cost, s.memberIds)
            _state.update { it.copy(done = true) }
        }
    }

    fun delete() {
        if (!_state.value.canDelete) return
        viewModelScope.launch {
            goals.delete(goalId)
            _state.update { it.copy(done = true) }
        }
    }
}
```

```kotlin
package com.gekkotron.kidquest.ui.settings

import androidx.lifecycle.ViewModel

import kotlinx.coroutines.flow.stateIn
import kotlinx.coroutines.launch

/** Parses "20", "+20", "-10", "−10" (U+2212). Returns null for 0, blank or garbage. */
fun parsePoints(text: String): Int? =
    text.trim().replace('−', '-').removePrefix("+").toIntOrNull()?.takeIf { it != 0 }

data class SettingsUiState(
    val children: List<Child> = emptyList(),
    val actions: List<PointAction> = emptyList(),
    val quickAmounts: List<QuickAmount> = emptyList(),
    val language: String? = null,
)

class SettingsViewModel(
    private val children: ChildRepository,
    private val settings: SettingsRepository,
) : ViewModel() {

    val state: StateFlow<SettingsUiState> = combine(
        children.observeAll(), settings.observeActions(), settings.observeQuickAmounts(), settings.observeLanguage(),
    ) { kids, actions, quick, lang -> SettingsUiState(kids, actions, quick, lang) }
        .stateIn(viewModelScope, SharingStarted.Eagerly, SettingsUiState())

    fun addChild(name: String, avatar: String, color: Long): Boolean {
        if (name.isBlank()) return false
        viewModelScope.launch { children.add(name, avatar, color) }
        return true
    }

    fun updateChild(child: Child): Boolean {
        if (child.name.isBlank()) return false
        viewModelScope.launch { children.update(child) }
        return true
    }

    fun setArchived(childId: Long, archived: Boolean) {
        viewModelScope.launch { children.setArchived(childId, archived) }
    }

    fun addAction(label: String, pointsText: String, icon: String): Boolean {
        val points = parsePoints(pointsText) ?: return false
        if (label.isBlank()) return false
        viewModelScope.launch { settings.addAction(label, points, icon) }
        return true
    }

    fun updateAction(action: PointAction, label: String, pointsText: String, icon: String): Boolean {
        val points = parsePoints(pointsText) ?: return false
        if (label.isBlank()) return false
        viewModelScope.launch { settings.updateAction(action.copy(label = label, points = points, icon = icon)) }
        return true
    }

    fun deleteAction(action: PointAction) {
        viewModelScope.launch { settings.deleteAction(action) }
    }

    fun moveAction(actionId: Long, up: Boolean) {
        viewModelScope.launch { settings.moveAction(actionId, up) }
    }

    fun addQuickAmount(pointsText: String): Boolean {
        val points = parsePoints(pointsText) ?: return false
        viewModelScope.launch { settings.addQuickAmount(points) }
        return true
    }

    fun updateQuickAmount(amount: QuickAmount, pointsText: String): Boolean {
        val points = parsePoints(pointsText) ?: return false
        viewModelScope.launch { settings.updateQuickAmount(amount.copy(points = points)) }
        return true
    }

    fun deleteQuickAmount(amount: QuickAmount) {
        viewModelScope.launch { settings.deleteQuickAmount(amount) }
    }

    fun moveQuickAmount(amountId: Long, up: Boolean) {
        viewModelScope.launch { settings.moveQuickAmount(amountId, up) }
    }

    fun setLanguage(tag: String?) {
        viewModelScope.launch { settings.setLanguage(tag) }
    }
}
```

**Deviations from the spec (intentional):**
- AGP 9 forbids `com.android.application` in a KMP module, so the Android entry point is a separate `androidApp` module and `composeApp` is a KMP library.
- `shared` and `composeApp` also target the JVM so repository/ViewModel/UI tests run without an emulator (spec said "Android/JVM host tests").
- ViewModel tests use the real repositories over an in-memory DB instead of fakes: faster to write, and they exercise the real queries.
- Added `GoalRepository.delete` for goals that were never redeemed (a parent needs to remove a mistaken goal).
- Restoring an undone REDEEM event is not offered; the parent redeems again instead (avoids re-redeeming a goal that may have dropped back to ACTIVE).
